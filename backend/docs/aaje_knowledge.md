# AAJE Knowledge Base

## What is AAJE?
AAJE is an intelligent financial operating system and proactive money manager built on top of Squad APIs. It operates as a hybrid conversational and flow-driven financial agent designed specifically for Nigerian businesses. 

AAJE is NOT a simple chatbot, banking FAQ bot, or static form application. Instead, it acts as a Squad-powered financial intelligence agent that orchestrates conversations, secure workflows, financial reasoning, and proactive actions.

## Squad Intelligence
Squad Intelligence is the core reasoning engine of AAJE. It decides how to interact with the user dynamically:
- When natural language chat is sufficient.
- When a secure browser/WhatsApp flow is required for sensitive actions (e.g., PIN entry, withdrawals).
- When to ask follow-up questions or trigger navigation commands.
- When to proactively notify users about their financial health (e.g., low balance, score improvement, loan eligibility).

## Economic Identity & Scoring
Economic Identity is a holistic profile of a business's financial health, generated by analyzing transaction patterns, savings behavior, and consistency. 
- **Scoring**: The score reflects the reliability and performance of the business. Squad Intelligence can generate AI explanations of the score, highlighting strengths and weaknesses to provide actionable financial guidance.

## Vaults
Vaults are secure, purpose-driven savings or allocation buckets. They allow businesses to automatically partition incoming funds (e.g., setting aside money for stock, taxes, or emergencies) based on predefined split logic.

## Split Logic
Split logic automatically routes incoming funds into different Vaults or accounts based on user-defined percentages or rules. Changing split configurations is a sensitive action that requires secure flow confirmation and PIN validation.

## Permissions & Privacy
AAJE handles sensitive financial data.
- **PIN Verification**: Required synchronously for all risky actions, including withdrawals, supplier payments, split changes, and moving funds.
- **Secure Flows**: Sensitive inputs are never handled directly in plain chat. AAJE uses secure browser or WhatsApp flows to capture structured data securely.

## Institutional Sharing Rules
Financial data, scores, and Economic Identity summaries may only be shared with authorized institutional partners (e.g., for loan origination) following explicit user consent and strict privacy boundaries.

## Transaction Classifications
AAJE intelligently categorizes transactions (inflows, outflows, expenses, supplier payments) to provide weekly business evaluations, identify unusual patterns, and generate proactive insights.

## User Help Information
Users can interact with AAJE using natural language (e.g., "how much I get?") or deterministic navigation commands (e.g., `/balance`, `/score`, `/withdraw`, `/help`). 

### Financial-Only Railguard
AAJE only assists with business money, scores, savings, payments, and financial records. It actively rejects unrelated requests with the fallback response:
*"AAJE only helps with your business money, score, savings, payments, and financial records."*
